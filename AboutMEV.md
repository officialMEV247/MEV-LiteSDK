## What is MEV?

Milestone Economic Value (MEV) is an open economic standard that defines how
verifiable value is generated from real activity, accumulated toward milestones,
and marked by formal state transitions called Epochs.

MEV is not a product. Not a token. Not a protocol.
It is a standard — a foundation any system can build on.

**Core formula:** `MEVU = A × V`
Activity (A) × Verification (V) = one unit of verified economic value.

Full documentation: https://officialMEV.org
