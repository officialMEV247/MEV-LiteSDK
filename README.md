# MEV Lite SDK — General Templates
> MEV Standard v1 · officialMEV.org

This folder contains the 11 general template declaration files for any
organisation implementing the MEV standard. Each file contains instructions
in [brackets] showing you exactly what to fill in.

## Files
01. AboutMEV.md        — Entry point
02. MEVLicense.md      — License declaration
03. MEVCertificate.md  — Certification proof
04. MEVU.md            — MEV Unit declaration
05. MEVEpoch.md        — Milestone formula and Epoch declaration
06. MEVDiapause.md     — Diapause phase declaration
07. MEVMRSS.md         — Rule Set Specification
08. MEVOracle.md       — Oracle configuration
09. MEVActivity.md     — Activity definition
10. MEVAdaptation.md   — Innovation declaration
11. MEVCompliance.md   — Compliance self-assessment

## How to use
1. Copy this folder into your project as /mev-sdk/
2. Fill in every field marked [in brackets]
3. When complete, submit MEVCompliance.md + your Implementation Paper
   to the MEV Foundation for certification review

Full documentation: https://officialMEV.org
