## Terms Summary

The MEV Open Standard License v1 grants any organisation or individual the right to:

- Freely adopt and implement the MEV standard in any system
- Author and publish a MEV Implementation Paper
- Use MEV terminology (MEVU, MEV Epoch, MEV Diapause, etc.) when describing
  a compliant implementation
- Reference officialMEV.org as the canonical source of the standard

The following require formal MEV Foundation approval:

- Use of the **MEV-Certified** mark
- Listing in the **MEV Global Registry**
- Publication of an **official MEV Implementation Paper** on officialMEV.org
